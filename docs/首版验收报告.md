## 五、已知边界（首版故意不做）

1. **没有注册登录**：用"昵称"代替账号，点赞/发帖不校验身份。
2. **不能发评论**：只展示种子评论。
3. **不能上传图片**：封面与头像用后端生成的内联 SVG（emoji 插画风），离线也不会裂图；首页顶部大图是外链图，已做断网兜底。
4. **没有部署上线**：首版是本机可运行。
5. 启动时会有 `ExperimentalWarning: SQLite` 提示，属 Node 正常提示，不影响使用。

## 六、待产品经理决策

1. **网站叫什么名字**？现在占位为"宠物社区"，改名只改 3 处。
2. 6 个分类（猫咪日常 / 狗狗生活 / 异宠天地 / 健康问诊 / 科学喂养 / 行为训练）够不够？
